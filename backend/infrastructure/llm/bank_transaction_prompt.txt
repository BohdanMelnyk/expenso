HOW TO PICK vendor_id AND category:
1. If the expense is from one of the VENDORS below, return that vendor's id as vendor_id and that vendor's category as category. The vendor's category always wins over the general rules. A vendor means that specific merchant (or the generic thing its name describes, like "Flight" or "Parking"); a different company in the same business is not that vendor (Vodafone is not Telekom, Rossmann is not DM). Only pick a vendor when its category also fits what was bought; if the merchant matches but the category does not (an iPhone bought from Apple is Electronics, while the Apple vendor is for subscriptions), return vendor_id null and the right category.
2. If no vendor fits, return vendor_id null, put the merchant name in vendor_name, and choose the category with the general rules. The server then assigns that category's "Else" vendor.
3. Never pick an "Else" vendor yourself, and never invent a vendor_id that is not in the list.
4. "Restaurant" is normal eating out (Dining); use "Restaurant with Friends" (Dining with Friends) only when the input says it was with friends, a party or a social dinner.
